# OSSライセンスガイド

このディレクトリは、OSSや無償公開されたコード、ライブラリ、コンテナイメージ、AIモデル、データなどを業務で扱う際の判断基準と運用手順を管理する。

- [OSSライセンス利用ガイドライン](./OSS_LICENSE_GUIDELINE.md): OSSを採用・利用・提供する際の基本原則、判断フロー、相談基準
- [OSSライセンスリファレンス](./OSS_LICENSE_REFERENCE.md): 主なライセンスの分類、義務、利用形態ごとの注意点
- [OSSライセンス運用ガイド](./OSS_LICENSE_OPERATION_GUIDE.md): 採用申請、開発、リリース、廃止までの実務手順

最初に利用可否を判断するときはガイドライン、個別ライセンスや利用形態を確認するときはリファレンス、証跡やリリース作業を整備するときは運用ガイドを参照する。

> [!IMPORTANT]
> これらの文書は一般的な実務指針であり、法的助言ではない。個別案件では、対象物の正確なライセンス本文、利用形態、契約、適用法を確認する。判断に迷う場合は、公開・納品・提供の前に法務・知財担当へ相談する。
